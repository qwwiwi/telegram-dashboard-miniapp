# Telegram-дашборд бизнеса: бот и мини-приложение

Скилл для AI-агента (Claude Code, Codex и похожих). Агент по нему собирает владельцу бизнеса личный дашборд прямо в Telegram: бот с кнопкой «Дашборд» и мини-приложение с цифрами по отделам.

## Что это

Вы открываете своего бота, нажимаете одну кнопку и видите цифры бизнеса:

- **Сводка** – 4–6 главных чисел и график выручки.
- **Маркетинг** – трафик, заявки, расходы на рекламу, стоимость заявки, каналы.
- **Продажи** – сделки, конверсия, выручка.
- **Финансы** – доходы, расходы, прибыль, остаток денег.

Отделы – пример. Свои разделы добавляются по одному рецепту из скилла.

## Зачем

- Цифры всегда в телефоне, без таблиц и без входа в пять кабинетов.
- Данные обновляются сами: маленькие скрипты-сборщики раз в час забирают числа из CRM, рекламы, банка или таблиц.
- Доступ только у вас и у тех, кого вы разрешили по Telegram-id.
- Всё живёт на одном недорогом сервере, база – один файл SQLite.

## Как это устроено

```
 Источники: CRM, реклама, банк, таблицы
        |  по расписанию
        v
 Сборщик --POST /ingest + ключ--> Backend (API) <--> База (SQLite)
                                      ^
                                      | запросы с токеном сессии
 Бот --кнопка «Дашборд»--> Telegram --> Мини-приложение (карточки и график)
```

## Как быстро создать

**1. Поставьте скилл агенту.**

```bash
git clone https://github.com/qwwiwi/telegram-dashboard-miniapp ~/.claude/skills/telegram-dashboard-miniapp
```

Для другого агента положите папку туда, где он читает скиллы, или просто дайте ему ссылку на этот репозиторий.

**2. Подготовьте четыре вещи.**

- Бот: в Telegram откройте @BotFather, команда `/newbot`, получите токен.
- Сервер на Linux с доступом по SSH.
- Домен, который смотрит на этот сервер (нужен HTTPS – Telegram открывает мини-приложения только по нему).
- Часовой пояс и валюта бизнеса.

**3. Скажите агенту:**

> Сделай мне дашборд бизнеса в Telegram по скиллу telegram-dashboard-miniapp. Отделы: маркетинг, продажи, финансы. Начни с демо-данных.

Агент пройдёт 8 шагов из `SKILL.md`: бот → сервер с проверкой входа → база → «Сводка» → отделы → сборщики → деплой с HTTPS → проверки. Сначала всё поднимается на демо-цифрах, потом подключаются настоящие источники.

## Как привязать вход к Telegram-id

Дашборд открывается только тем, чей числовой Telegram-id есть в списке разрешённых.

**1. Узнайте свой id.** Напишите вашему боту любое слово. Агент один раз вызовет `getUpdates` и возьмёт число из `message.from.id`. Это число, а не @username.

**2. Впишите id в настройки на сервере.** В файлах настроек бота и backend:

```
ALLOWED_TG_IDS=111111111
```

Несколько человек – через запятую: `ALLOWED_TG_IDS=111111111,222222222`.

**3. Перезапустите службы.** После этого бот отвечает вам кнопкой «Дашборд», а чужим – «Нет доступа.»

**Как это защищено.** Когда вы открываете мини-приложение, Telegram передаёт странице строку `initData` с вашим id, подписанную токеном бота. Сервер проверяет подпись, затем ищет id в списке и только после этого отдаёт цифры. Подделать id со стороны страницы нельзя: проверка идёт на сервере при каждом запросе.

**Как убрать доступ.** Человеку ставится отметка отзыва в таблице `allowed_users`, и вход в дашборд закрывается сразу, без перезапуска. Чтобы бот перестал показывать кнопку, id убирают и из `ALLOWED_TG_IDS`.

## База данных: SQLite или свой Supabase

Сначала база – один файл SQLite: ничего ставить не нужно. Если вы хотите смотреть таблицы в окне Supabase, или в базу пишут несколько программ, скажите агенту:

> Переведи дашборд с SQLite на Supabase/Postgres по `references/postgres.md`.

Агент поставит Supabase из открытого кода на ваш сервер (по официальной инструкции Supabase для Docker, нужно от 4 ГБ памяти), закроет порт базы от интернета, заведёт дашборду отдельную роль со своим паролем, перенесёт старые цифры и настроит копии. Без настройки `DATABASE_URL` всё остаётся на SQLite. Что в этом пути проверено запуском и что нет – написано в конце `references/postgres.md`.

## Что внутри

| Файл | Для чего |
|---|---|
| `GUIDE.md` | Единый гайд для владельца: какие цифры и графики нужны, как это устроено в скилле, готовые фразы агенту |
| `SKILL.md` | Главная инструкция агенту: порядок сборки, пример с отделами, рецепт нового раздела, безопасность, типичные ошибки, чек-лист |
| `references/database.md` | Как устроить базу: таблицы, запросы, правила хранения чисел |
| `references/postgres.md` | Переход с SQLite на Postgres или свой Supabase: правки кода, подключение, перенос данных, копии, чек-лист |
| `references/starter.md` | Рабочий каркас кода: backend на FastAPI, страница мини-приложения, бот, сборщик, тесты, деплой |

## Важно

- Токен бота и ключи – только в файлах настроек на сервере. Не в чат, не в git.
- Каркас проверен тестами и локальным запуском. На вашем сервере агент проверяет всё заново по чек-листу из `SKILL.md`.
- Деплой и перезапуски агент делает только после вашего «да».
