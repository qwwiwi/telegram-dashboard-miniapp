# Панель бизнеса

1. Скопируйте `dashboard.html` и откройте двойным щелчком в браузере.
2. Попросите своего ИИ-агента заменить только объект `const DATA` под отметкой «ЗАМЕНИТЕ ЭТИ ДАННЫЕ».
3. Передайте агенту выгрузки рекламы, CRM и финансов. Секреты в HTML не добавляйте.
4. Выберите период 7, 30 или 90 дней и нужный раздел.

## Что передать агенту

- `company`, `updatedAt` (дата со смещением часового пояса), `endDate` (последний день отчёта).
- `departments`, `metrics`: разделы и подписи карточек; сохраните существующие идентификаторы.
- `daily`: дневные данные за 180 дней для сравнения двух периодов по 90 дней.
- Денежные значения – в рублях; даты строк – `ГГГГ-ММ-ДД`, без повторений.
- `revenue` – доходы, `expenses` – все расходы, включая `adSpend`; прибыль = доходы − расходы.
- `cash` – остаток денег на конец дня; это снимок, а не сумма за период.
- `traffic`, `leads`, `qualified`, `proposals`, `deals` – количества; этапы воронки относятся к одной группе заявок.
- `cycleDays` – сумма длительности цикла оплаченных сделок; среднее = сумма / число сделок.
- `channels` и `costs` в каждой строке – суммы по категориям в порядке `channels` и `expenseCategories`.
- Сумма каналов должна совпадать с заявками, сумма статей расходов – с общими расходами.
- `latestDeals`: последние сделки с датой, условным названием, суммой и статусом.

## Пропуски и сравнение

Отсутствующий день или `null` означает «нет данных», число `0` – настоящий ноль.
График не соединяет пропуски; неполные итоговые показатели заменяются на «–».
Для нулевой базы процент изменения не вычисляется. Для расходов снижение считается улучшением.
В демо есть пропуски; заполните их реальными данными, чтобы получить полные итоги.
Нажмите на график или откройте «Показать таблицей» для точных значений.

## Размещение

Файл работает без сборки, библиотек и сетевых запросов. Все данные доступны читателю файла.
Для мини-приложения разместите HTML на своём защищённом веб-сервере и укажите его адрес в настройках бота.
Если оболочка передаёт `window.Telegram.WebApp.themeParams`, цвета берутся из неё; иначе – из темы устройства.
После объекта есть закомментированный пример подключения своего API: сервер должен вернуть ту же структуру и историю за 180 дней.
При подключении API перенесите инициализацию в асинхронную функцию и обработайте ошибку загрузки.
